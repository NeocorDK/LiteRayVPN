# LiteRay

Лёгкий и простой клиент для Xray под Windows 10/11.

- **Протоколы:** VLESS (REALITY / TLS; tcp, xhttp, ws, grpc, httpupgrade), VMess, Trojan, Shadowsocks.
- **Подписки** (3X-UI, Marzban и другие, формат v2rayN) с автообновлением. Показывает остаток трафика и срок действия.
- **Два режима:**
  - **TUN** — весь трафик компьютера, нужны права администратора;
  - **системный прокси** — без прав администратора.
- **Split-tunneling:**
  - по приложениям: exe, папка целиком, выбор из запущенных;
  - по доменам;
  - по IP и подсетям;
  - готовые правила: «Российские сайты и IP напрямую», «Локальная сеть напрямую», «Блокировать рекламу».
  - Два режима списка: «всё через VPN, кроме…» и «только список через VPN».
- **Пинг и скорость:** реальная задержка через туннель, скорость загрузки и отдачи, график за минуту.
- **Обновление ядра и геобаз** из GitHub с проверкой SHA-256.
- **Сборки:** portable и установщик. Интерфейс на русском и английском.

## Установка

- **Установщик** `LiteRay_<версия>_x64-setup.exe` ставит программу для текущего пользователя.
- **Portable** `LiteRay_<версия>_x64-portable.zip`: распакуйте в любую папку. Настройки хранятся рядом с программой, в папке `data`.

Нужен WebView2 Runtime. В Windows 10/11 он обычно уже установлен, установщик при необходимости поставит его сам.

## Как пользоваться

1. Вкладка **Серверы**: вставьте ссылку подписки (`https://…`) или ссылки `vless://…`, затем нажмите **Добавить**.
2. Выберите сервер.
3. На **Главной** нажмите кнопку подключения.

   В режиме TUN программа попросит права администратора. Чтобы не подтверждать UAC при каждом запуске, включите в **Настройках** «Запускать вместе с Windows»: тогда автозапуск идёт через Планировщик задач.
4. Вкладка **Маршруты**: исключения. Правила применяются сразу, даже при активном подключении.

Закрытие окна сворачивает программу в трей. Выход — через меню иконки в трее.

## Сборка из исходников

Требуются Node.js 20+, Rust (stable, MSVC) и Visual Studio Build Tools с компонентом C++.

```powershell
npm install
npm run fetch-core   # xray.exe, wintun.dll, geoip.dat, geosite.dat
npx tauri dev        # запуск для разработки
npm run release      # установщик и portable-архив в release/
```

Тесты: `cd src-tauri; cargo test`.
